חלונות

מה המפרסם מקבל

הלוח היומי: עיצוב חדש

היום וואטסאפ מציג תצוגה מקדימה של הקישור הראשון בהודעה. הקישור הראשון הוא של המפה, ולכן מופיעה תמונה של גוגל מפות מעל הלוח.

WhatsApp previews the first link in a message. Today that is the map link, so a Google Maps tile sits on top of the board.

לפניBefore: long form, map link first → map preview
אחריAfter: short form, bold, FOMO card as preview

מה משתנה בלוח

  1. קישור FOMO בראש ההודעה, לעמוד "מה עושים היום" עם כרטיס ממותג. וואטסאפ יציג את הכרטיס הזה במקום את המפה.
    A FOMO "today" link first, with a branded preview card; WhatsApp shows that instead of the map.
  2. בלי קישור מפה בלוח. המפה נמצאת בעמוד של האירוע, מאחורי הקישור 🔗.
    No map link on the board; the event page behind 🔗 has it.
  3. הדגשה: הכותרת, התאריך, והשעה והשם של כל אירוע מודגשים, כך שקל לסרוק את הרשימה.
    Bold title, date, and each event's time and name, so the list scans quickly.
  4. שורה וחצי לאירוע במקום 5–7 שורות. הפירוט המלא נשאר למודעה הגרפית.
    About 1.5 lines per event instead of 5–7; the full pitch belongs to the ad.

מה יוצא מהקוד

What comes out of the code (for Tom)

  • Slot handoff: the board post (makeWeekly, label "הלוח") and the "promoted" section are removed from buildSlotPosts; ads scheduled for a window take their place.
  • make-weekly.js, send-weekly.js and the /weekly route go; the formatters drop "weekly board" comments.
  • Copy: publishChoicePrompt, NO_DAILY_TEXT, the "לא, רק בלוח השבועי" option and the review notice's "בלוח השבועי" label are rewritten.
  • daily_days (pick-a-day for the daily message) is replaced by an ad booking: date + window (morning/evening).
  • The publish-day question moves out of the submission receipt; it is asked only in notifyApproved, as a separate message.
  • Template fomo_publish_day_v2 names the old options; it needs new wording and Meta approval before the buttons version can go out.
  • The weekly publisher nudge (Wednesday 18:00) is a reminder to submitters, not the board, and stays.
