# Event Submission Template

The bot accepts free text, but this is the recommended format to show users.

## Hebrew

```text
שם האירוע:
קטגוריה:
גאנרים:
תאריך מדויק:
שעת התחלה:
מיקום:
מחיר / חינם:
איש קשר:
קישור:
תיאור קצר:
תמונה / פלייר:
```

## English Reference

```text
Event name:
Category:
Genres:
Exact date:
Start time:
Location:
Price/free:
Contact person:
Link:
Short description:
Image/flyer:
```

## Required Fields

- Event name.
- Category.
- Exact date.
- Start time.
- Location.
- Price/free.
- Contact person.
- Image/flyer.

## Recommended

- Link.

## Optional

- Genres.
- Short description.
